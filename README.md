# 📅 Cafe1947 Reservation & Booking Management System

Welcome to the **Cafe1947 Reservation and Booking Management System** – a fully-featured, dynamic platform built with **Python** and **Streamlit**, designed to seamlessly manage table and event bookings for Cafe1947. The system is fully integrated with the **Cafe1947 main website**, providing a responsive, interactive experience for staff and managers.

---

## 🚀 Features

### **Booking Management**
- Add, view, and manage **table or event reservations** in real-time.
- Filter bookings by **month, year, or guest count**.
- Interactive **metrics dashboard**:
  - Total Guests
  - Average Guests per Booking
- Delete bookings dynamically with instant updates.
- Expandable booking details for quick review of each reservation.

### **Dynamic Data Handling**
- Built with **Pandas**, enabling smooth **data filtering, aggregation, and visualization**.
- Supports **month/year filtering**, **summary statistics**, and **dynamic charts**.
- All updates are **instantaneously reflected** on the dashboard.

### **Integration with Cafe1947 Website**
- Linked to the main **Cafe1947 portal**, allowing seamless navigation between the website and the Streamlit app.
- Fully compatible with web-based deployment, accessible from any device.

### **User-Friendly Interface**
- Interactive **Streamlit UI** with:
  - Radio buttons for navigation (`All Data`, `By Month`, `Summary`, `Delete`)
  - Metrics for quick insights
  - Expandable booking details for ease of use
- Designed for **simple, intuitive operation** while providing detailed insights for managers.

---

## 💻 Tech Stack

- **Python 3.11+**
- **Streamlit** for interactive dashboards
- **Pandas & NumPy** for data manipulation
- **Matplotlib / Streamlit Charts** for visualization
- Optional integration with **Notion API** for archival or syncing data
